# Native OpenCode Go translation review

Reviewed against the actual `packages/gateway/src/services/opencode-go-fetch.ts` and reused canonical `llm_headers`/`bounded_json` implementations. The native module owns protocol selection, request translation, JSON completion translation, incremental SSE conversion and response-body cancellation. It receives the authorized fetch effect; it does not create a client, resolve hosts, retry, spawn work, or add execution authority.

Actual TypeScript comparisons use the existing bounded internal driver with an injected fetch effect and pull-based byte stream. Seven groups cover 146 scenarios: 41 dispatch/request; 32 JSON completion/fetch; 13 Messages streaming; 20 Responses/error streaming; 12 framing/cancel/isolation; 11 malformed null shapes; 17 image URL coercion/header normalization. Result cardinality is asserted. Four shared driver checks, four native body-lifecycle/budget tests and one explicit Unicode compatibility test make 16 focused checks total.

Request tests cover model-family/Go URL detection, Messages role merging/system text/tool results/image sources/tool arguments, Responses tools/reasoning/token settings, explicit versus default headers, passthrough and non-OK statuses. Streaming tests cover tool indices, reasoning/text/arguments, usage/finish reasons, fragmented UTF8/BOM/CRLF/data frames, reader errors/premature EOF, cancellation and per-response isolation. Canonical JsonGraph serialization preserves JavaScript numeric formatting and numeric object-key order. Review found and fixed null elements silently skipped where TypeScript throws; the regression failed before the fix and passes after it.

Native-only bounds fail closed: raw and translated request bytes; response bytes; input frame/output frame bytes; upstream read events (including empty chunks); per-fetch/per-read deadlines; cancellation before effects and during blocked reads. Drop, error and deadline synchronously cancel the upstream source. The caller must provide a cancellation-safe fetch future/reader whose borrowed future drop revokes transport work, and owns its outer turn deadline and authorization. Defaults are 1 MiB requests/frames/output frames, 8 MiB response, 65,536 reads and a 30-second per-fetch/per-read timeout. Ordinary Chat Completions and non-OK upstream responses remain caller-owned passthrough, matching the reference.

Intentional compatibility restriction: Rust rejects unpaired UTF16 surrogates. Actual TypeScript request/stream probes record acceptance by the reference; native requests fail before outbound effect and native malformed streams cancel upstream. There is no claim of accepting all JavaScript non-JSON values; the boundary is JSON.

Eight compiler-fresh controls alter model dispatch, cache usage accounting, streamed tool indexing, upstream cancellation, null stream rejection, empty-chunk admission, header duplicate joining and image URL coercion. Each must fail a focused behavioral contract and show native recompilation before restoration. Frozen and restored hashes, command logs and results are in `.jait/artifacts/gateway-rust/continuation-opencode-go/`.

This review is component acceptance evidence only. Host composition, replacement, platform/load/soak/recovery gates and production activation remain separate. No production activation or service mounting is performed by this slice.
